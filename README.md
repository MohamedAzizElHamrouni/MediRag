# MediRag
🤖 Assistant médical intelligent basé sur l’IA générative, combinant LLM, LangChain, RAG, FAISS, PubMed et OpenFDA. Développé avec Python et Streamlit, il fournit des réponses médicales contextualisées, facilite la recherche d’informations scientifiques et intègre plusieurs outils spécialisés dans une interface conversationnelle interactive.
